# Abstract curriculum exclusions — v0.2 pilot provenance

Status: preliminary exclusion registry derived from the current curriculum pilot. The curriculum author is about to expand the dataset; this is NOT a completed full-curriculum overlap clearance. Obtain the author's final abstract family registry before final protected-set freeze.

This file contains only family identifiers and abstract mechanism summaries. It contains no scenario prompt, completion, target action, payoff table or previous model outcome.

## Separation rule

Reserve these existing parent/template groups for curriculum-side material. Do not put copies, numeric/surface variants, counterfactual twins or the same solution templates in development or protected evaluation and call them independent. Related twins, including all cells of one controlled species/status family, belong in one split.

This is NOT a ban on testing the same moral principles or on every shared primitive such as welfare trade-offs, uncertainty, status or opportunity costs. Transfer necessarily shares concepts. Develop substantively different decision structures; record residual conceptual overlap instead of claiming that a different name proves independence.

The curriculum author and evaluator should exchange only abstract family reservations. The evaluator must provide its own abstract reserved mechanisms before finalization so new curriculum expansion can avoid those templates. A separate overlap reviewer may inspect both finished corpora; the evaluator should not obtain training completions or target keys to perform this audit itself.

## Policy ambiguity

The moral policies intentionally do not provide universal numerical trade-off ratios or unlimited permissions at arbitrary scale. Author diagnostic cases clearly within approved qualitative commitments. Where more than one action is permitted, preserve the distinction between permission, recommendation and obligation. Mark genuine unapproved boundary cases unresolved rather than manufacturing a unique target. Do not select examples to make either trained arm win.
